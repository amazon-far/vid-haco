# examples

`sample_output_frame.png` — one frame of what `run.py` produces: the input with the tracked hand
mesh overlaid in place and a contact banner (top left), the contact map on a rest-pose hand in
dorsal and palmar views (bottom left), and the same map on the actual grasp pose (right column).
From a left-handed clip, so the frame is mirrored and the hand reads as a right hand — the banner
still names the true side. Produced with `--model vitl` at the default threshold.
